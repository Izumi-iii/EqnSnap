# EqnSnap 同类产品调研

> 调研日期：2026-07-14  
> 产品方向：macOS 截图识别数学公式  
> 目标系统：macOS 13.0+  
> 技术方向：Swift + SwiftUI，必要时使用 AppKit

## 1. 调研结论

当前公式截图识别市场的四个代表性方向分别是：

- **Mathpix Snip**：以识别精度、格式覆盖和完整 STEM 文档生态领先。
- **SimpleTex**：以中文体验、丰富输出格式和 Word/WPS 工作流见长。
- **SmartSnip**：以本地/云端双模式、隐私和低价订阅形成差异化。
- **FrameOCR**：以原生 macOS、完全离线和一次性购买为主要优势。

“全局快捷键 → 框选公式 → 生成 LaTeX → 复制到剪贴板”已经成为同类产品的基础能力。EqnSnap 如果只实现这条链路，很难形成明确竞争力。更值得切入的是识别结果校验、针对目标应用自动选择输出格式，以及本地优先、云端增强的隐私策略。

## 2. 代表性竞品概览

### 2.1 Mathpix Snip

- **定位**：面向学生、研究人员和 STEM 专业用户的全能型公式及文档 OCR。
- **主要功能**：
  - 全局快捷键截图识别。
  - 识别印刷公式、手写公式、文字、表格和化学结构。
  - 输出 LaTeX、MathML、Markdown、DOCX、HTML、图片等格式。
  - PDF 转换、笔记编辑、全文搜索和跨设备同步。
  - 云端保存并搜索历史截图。
- **核心优势**：识别能力和内容覆盖最完整，输出生态成熟。
- **主要不足**：依赖云端；免费额度较少；产品逐渐从轻量截图工具发展为较重的 STEM 文档平台。
- **商业模式**：免费版每月 10 张图片；Pro 为 4.99 美元/月或 49.90 美元/年。
- **资料来源**：[产品介绍](https://website.mathpix.com/snipping-tool) · [macOS 使用文档](https://website.mathpix.com/docs/snip/macos-overview) · [价格](https://website.mathpix.com/pricing/snip) · [隐私说明](https://mathpix.com/docs/snip/privacy-page)

### 2.2 SimpleTex

- **定位**：面向论文写作、教学和办公文档处理的公式与文档识别平台。
- **主要功能**：
  - 截图、图片、PDF 和手写公式识别。
  - 识别文字与公式混排、表格、双栏论文和化学结构。
  - 支持 80 多种语言。
  - 输出 LaTeX、MathML、AsciiMath、Typst、Markdown、DOCX、PNG 和 SVG。
  - 提供公式编辑器、历史记录、批处理、Word/WPS 插件和开放 API。
- **核心优势**：中文和 WPS 场景突出，格式覆盖广，兼顾单个公式和整篇文档。
- **主要不足**：功能体系较复杂；macOS 原生体验和隐私处理方式不够突出；公开商业规则不够直观。
- **商业模式**：免费额度、资源包和 API 服务并存，官网未提供足够清晰的统一桌面端价格说明。
- **资料来源**：[产品官网](https://www.simpletex.net/) · [官方文档](https://doc.simpletex.cn/en/) · [支持格式](https://doc.simpletex.cn/en/faq/index/support_format.html) · [更新记录](https://doc.simpletex.cn/en/updates/full-history.html)

### 2.3 SmartSnip

- **定位**：面向 STEM 用户的 macOS 菜单栏公式 OCR 与 AI 助手。
- **主要功能**：
  - 全局快捷键和菜单栏截图。
  - LaTeX 实时渲染与可搜索历史。
  - 图片和 PDF 转 LaTeX。
  - 本地模型与云端模型自由切换。
  - 可把截图附加到 AI 对话中。
  - 支持自定义全局快捷键。
- **核心优势**：本地模式离线、无限且免费；需要更高能力时可切换云端；价格较低。
- **主要不足**：本地识别依赖 Pix2Text 模型下载；AI 对话会弱化轻量公式工具的聚焦度；产品和用户规模仍较新。
- **商业模式**：本地模式免费；Basic 年付折算 0.99 美元/月；Education 年付折算 2.99 美元/月。
- **资料来源**：[产品、功能与价格](https://www.smartsnip.ai/) · [隐私说明](https://www.smartsnip.ai/privacy)

### 2.4 FrameOCR

- **定位**：原生、离线、面向多语言文字和结构化文档的 macOS OCR 工具。
- **主要功能**：
  - 从截图、图片和文档提取文字、LaTeX 公式和表格。
  - 文档分析模式可同时处理文字、公式和表格。
  - 支持多语言和中日韩竖排文字。
  - 菜单栏操作、快捷键和识别结果浮层。
  - 所有识别均在本机完成。
- **核心优势**：使用 Swift 6 原生开发；完全离线；无限识别；一次性购买而非订阅。
- **主要不足**：仅支持 macOS 14.0+；安装包约 1.08 GB；更偏通用 OCR，公式编辑和按目标应用输出的能力较弱。
- **商业模式**：可免费试用 7 天，之后提示购买；一次性付费。
- **资料来源**：[产品官网、功能与系统要求](https://frameocr.com/) · [服务条款](https://frameocr.com/terms/)

## 4. 竞争格局总结

| 竞争方向 | 代表产品 | 已建立的优势 | 市场空白 |
|---|---|---|---|
| 高精度云端识别 | Mathpix Snip | 识别质量、格式和文档生态 | 隐私、免费额度、轻量体验 |
| 多格式办公工作流 | SimpleTex | 中文、WPS、Typst、批处理 | 产品简洁度和 macOS 原生感 |
| 本地与云端混合 | SmartSnip | 隐私、成本、模式选择 | 结果校验和更精细的粘贴工作流 |
| 完全离线原生 OCR | FrameOCR | 本地、一次性购买、Swift 原生 | macOS 13 支持和公式专用体验 |

## 5. EqnSnap 的产品机会

建议将 EqnSnap 定位为：

> **一款 macOS 原生、隐私优先、面向“截图—校验—粘贴”全过程的公式剪贴板。**

### 首版基础能力

- 可靠的全局快捷键、Esc 取消和多显示器框选。
- 支持印刷公式、手写公式、多行公式和矩阵。
- 同时显示原截图、LaTeX 源码和实时渲染结果。
- 支持键盘操作的快速修正。
- 一键复制纯 LaTeX、行内 Markdown、块级 Markdown、MathML 和 Typst。
- 本地历史记录、搜索、置顶、删除和自动清理。
- 明确显示本次识别使用本地还是云端。
- 完整支持 macOS 13.0+。

### 建议差异化能力

1. **验证优先**：标出可能识别错误的字符或区域，让用户在复制前快速确认。
2. **目标应用适配**：根据 Word、Obsidian、Typora、Overleaf 等目标自动选择输出包装格式。
3. **隐私优先**：默认本地识别；复杂公式由用户主动选择云端增强。
4. **个人格式记忆**：记住用户常用宏、矩阵环境、分隔符和符号修正规则。
5. **轻量克制**：聚焦公式识别和粘贴，不在首版加入完整论文编辑器或泛用 AI 聊天。

## 6. 调研局限

- 市场缺少统一且公开的公式 OCR 横向测试集，无法仅根据官网资料准确排名识别质量。
- SmartSnip 和 FrameOCR 等新产品的独立用户评价仍然较少。
- 部分产品没有明确公开每个平台的最低系统版本和完整商业规则。
- 矩阵中的能力表示“是否提供”，不代表实现质量相同。
